# Lamp

Lamp Built Using HTML, CSS and JavaScript.

![Lamp Screenshot](./Screenshot%202024-08-22%20142216.png)

## Demo
Open `index.html` in your browser to see the lamp in action. Use the slider to change the lamp's brightness.

## Features
- Pure HTML & CSS lamp design with minimal JavaScript for interaction.
- Smooth brightness control using a range slider.
- Responsive, simple, and easy to customize.

## How to use
1. Clone the repository:

   git clone https://github.com/BinaryVortex/Lamp.git

2. Open `index.html` in your preferred browser.
3. Move the slider to increase or decrease the lamp's brightness. The page uses a data attribute on the `body` element to change light levels.

## Files
- `index.html` — Markup and the slider control.
- `style.css` — All styling and brightness states.
- `Screenshot 2024-08-22 142216.png` — Screenshot shown above.

## Customize
- Edit `style.css` to change colors, size, or animation.
- Modify the range input in `index.html` to change min/max steps or default value.
